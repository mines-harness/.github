Mines brings coding agents into one workspace across desktop, web, and mobile. Run agents through their native provider tools, keep projects on their owning host, and connect from another approved device.

- Organize mines, projects, groups, and pinned work in one library.
- Compare models or work with a group of existing agents.
- Use your own provider accounts and inspect supported imported histories.
- Connect computers and phones through authenticated direct device connections.

Platform support and delivery status are recorded per release. Mobile previews, code checks, signing, and live device sessions have separate validation; read the repository notes before installing.
